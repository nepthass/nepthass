# v1.0.0-rc.1 manual Discord smoke checklist

Status: **not executed**. Record the tester, date, exact candidate commit and result for every row. Do not mark a section passed from automated-test evidence alone.

## Preconditions

- Use a dedicated Discord test guild and bot application, never a production community.
- Use an isolated Home Assistant test instance with virtual devices, never real safety or access-control devices.
- Build and run the exact candidate commit that will be tagged.
- Back up the candidate database before upgrade or rollback exercises.
- Prepare four Discord identities: configured administrator, configured regular user, unlisted outsider, and an identity in another guild. A direct-message attempt is also required.
- Configure at least one light, one switch, one supported binary sensor, one numeric sensor and one unavailable entity.
- Use a private notification channel whose membership and bot permissions are known.
- Never paste tokens into Discord, screenshots or this checklist.

Use `PASS`, `FAIL`, `BLOCKED` or `NOT RUN` in the Result column.
